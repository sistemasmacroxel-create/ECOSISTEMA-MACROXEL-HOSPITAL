MACROXEL HPS · QUIRÓFANO STOCK · INTEGRACIÓN ECOSISTEMA v3

- Todo el visor vive dentro de: MACROXEL-VISORES-CENTRAL/QUIROFANO-STOCK-ANTIBIOTICOS/
- App canónica: QUIROFANO_STOCK.
- Se reconoce también el alias legado MACROXEL_QUIROFANO_STOCK.
- Vinculación con el Sistema Principal: mismo mecanismo que los demás visores.
  1) Primero valida la ruta GitHub exacta en /ecosystem_connection/route_bindings.
  2) Si la ruta todavía no fue publicada, usa la base GitHub del Sistema Principal en /ecosystem_connection/github_bases.
  3) Si el Sistema Principal abrió el visor con mxSystem, el ID debe coincidir con la asociación encontrada; si no coincide, se bloquea para evitar cruces entre instalaciones.
- No contiene ID de Sistema Principal fijo ni URL operativa Firebase fija.
- La única URL común del ecosistema usada para descubrir la asociación es la base de control central. La Firebase operativa se obtiene en tiempo real del Sistema Principal asociado.
- El Sistema Principal de escritorio y la versión web reconocen QUIROFANO_STOCK en la matriz de rutas y en activaciones.
- La activación se guarda en /viewer_licenses/{SYSTEM_ID}/{DEVICE_ID} dentro de la Firebase operativa del Sistema Principal asociado.
